# Simple CLI Calculator

A small command-line calculator written in Python. It supports basic
arithmetic operations and is designed as a simple demonstration project
for learning Git and GitHub workflows (branching, merging, and conflict
resolution).

**Features:** Addition, Subtraction

## Requirements

- Python 3.8 or later
- No external dependencies

## Usage

Run the program:

```bash
python calculator.py
```

Example session:

```
================================
        SIMPLE CALCULATOR
================================
Available operations: add, subtract
Enter first number:  10
Enter second number: 4
Enter operation: add
Result: 14.0
```
